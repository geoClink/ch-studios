Overview

A 14-page marketing and booking site for a luxury hair salon — hand-written HTML, CSS, and JavaScript with no framework, no CMS, and no recurring cost. A direct alternative to Squarespace for salon owners who want something custom that's actually theirs.

The Problem

Salon owners pay $30–150/month for Squarespace or similar platforms. The sites look like everyone else's, lack salon-specific features, and the owner is always one price increase away from losing access to their own web presence.

What We Built

Gallery & Portfolio

Filterable work showcase using JavaScript class toggling. No library, no build step — just fast, accessible filtering across all service categories.

Services & Pricing

Full services page with descriptions, pricing, and booking CTAs organized by category. Easy to scan, easy to update.

Smart Navigation

IntersectionObserver-powered sticky header that activates on scroll without layout shift. Zero JavaScript overhead at page load.

CSS Carousel

Auto-rotating image gallery built with pure CSS animation. No JavaScript, no library — runs with zero runtime overhead.

Booking & Contact

Formspree-powered inquiry form routed directly to the owner's inbox. Appointment requests and consultation bookings handled without a backend.

Zero-Dependency Performance

100/100/100 Lighthouse across Performance, Accessibility, and SEO. Sub-second load, no build pipeline, no external dependencies.
